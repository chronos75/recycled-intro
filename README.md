# Recycled Intro

**Version:** 1.0  
**Development:** 2019  
**Platform:** Commodore Plus/4  
**Language:** 6502 assembly  
**Assembler:** KickAssembler  
**Status:** Completed and tested; archived for preservation

## About

A classic C64-style crack intro related to Nifty Intro, featuring Absence logos at the top and bottom with changing color schemes. Unlike Nifty Intro, it uses a 1×1 character set.

It includes a functional trainer menu and memory-copy routine. These are templates and must be customized for each release.

## Music credits

- **Contrast** — **Adam Dunkels (Trident)** (1994)

The original C64 SID music can be played via a SID card or the Plus/4 TED sound hardware.

## Building

The sources have been converted to **KickAssembler**. Earlier references to DASM, as65 or Plus4IDE describe historical development tools, not current build requirements. The original source files are preserved without modification.
